# assets/

- `vets/<id>/` : ảnh của từng bệnh viện / phòng khám thú y (vc1 … vc9, trùng `id` trong `VET_CLINICS` ở `js/map.js`).
  - `logo.jpg` : logo, `g1..gN.jpg` : ảnh bìa + ảnh phòng khám, `d1..dN.jpg` : ảnh bác sĩ.
  - Danh sách ảnh và chú thích bác sĩ khai báo trong `data/vet-images.js`. Muốn thêm/bớt ảnh chỉ cần chép file vào đúng thư mục rồi sửa file này.
